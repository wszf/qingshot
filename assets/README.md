# QingShot icon

`AppIcon.png` is the original transparent raster master. `scripts/build-icon.sh` generates the macOS 16–1024 px icon representations and `.icns` bundle using Apple's `sips` and `iconutil` tools. Generated sizes stay in `.build/`.

Design: jade and mint rounded-square tile, white capture brackets forming a Q, and a small warm capture glint. The artwork was generated for this project using OpenAI's built-in image generation tool, then converted to standard macOS icon sizes. It is included under the repository's MIT license.

Generation prompt:

> Single centered macOS rounded-square tile on a transparent canvas. Rich jade-green to mint gradient, restrained satin depth. White geometric capture/viewfinder brackets form a compact Q silhouette with a diagonal lower-right tail and one tiny warm cream glint. Clear at small sizes, balanced geometry, generous breathing room. No text, watermark, mockup, props or extra variants; transparency outside the tile.
